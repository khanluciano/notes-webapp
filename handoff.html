Project Handoff Documentation

Overview & Architecture

  • Backend: Go (net/http, text/template, bcrypt, lib/pq)
  • Database: PostgreSQL
  • Frontend: Vanilla HTML5, CSS3, JavaScript (Go HTML Templates)
  • Authentication: Cookie-based session tracking (user_id HTTP-only cookie)

Initial State vs. Final Implementation

Area Initial State Current Implemented Solution
Form Error UX Redirects or plain text errors. Inline styled error banners beneath input fields.
Password Validation Unrestricted length. Enforced 6 to 25 characters (front/back-end).
Username Validation Basic check with redirects. Enforced 4 to 15 characters, unique DB index.
Delete Confirmation Browser default confirm() popup. Custom dark-themed CSS modal dialog.

Database Schema

CREATE TABLE IF NOT EXISTS users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(15) UNIQUE NOT NULL,
    password TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS notes (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title TEXT NOT NULL,
    content TEXT NOT NULL
);
